怎么用

三步，开口就是另一个人。

装好 Shizuku，选个音色，剩下的交给手机上的模型。

01

装好 Shizuku 并授权

安装并启动 Shizuku，在 MicMask 内完成授权，变声即可注入系统麦克风。

02

下载或导入音色

从内置音色仓库一键下载，或导入自己的 .pth（可同时选中 .index）。

03

开始变声

点「开始变声」，直接打开 QQ 或游戏说话，原应用原样使用。

    常见问题

    开口之前，先问清楚。

    需要 ROOT 吗？

    不需要。MicMask 借助 Shizuku 拿到的 shell 权限工作，手机无需解锁 Bootloader 或刷机。

    对手机有什么要求？

    需要 64 位 Android 手机。推荐骁龙 8 Gen2 / Gen3 等旗舰芯片；中端机也能用，切到 0.5s 档更稳。

    需要把 QQ 装进虚拟机吗？

    不需要。原应用直接使用，MicMask 自动识别正在录音的目标应用并接管麦克风。

    收费吗？

    免费，并且以 GPL-3.0 协议开源。赞助完全自愿，不影响任何功能。

    会上传我的声音吗？

    不会。全部为本地推理，音频不离开你的手机。

    没有 Shizuku 能用吗？

    可以用普通模式（外放 / 录播回退），但效果有限，实时通话场景仍建议配合 Shizuku。

    怎么反馈问题？

    在 App 的日志页导出日志，加 QQ 群 780988679，或到 GitHub Issues 提交，附上日志更好定位问题。
