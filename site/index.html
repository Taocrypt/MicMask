怎么用

三步，开口就是另一副嗓子

第一次大约几分钟。之后打开 MicMask，点一下「开始变声」就行。

授权 Shizuku

安装并启动 Shizuku，在 MicMask 里点授权。变声会以 shell 身份注入系统麦克风，手机不用 Root。

选或导入音色

从内置音色仓库一键下载，或者直接在手机上导入自己的 .pth 模型，可同时带上 .index 检索索引。

打开应用直接说话

点「开始变声」，然后照常打开 QQ、微信或游戏开麦。原应用原样使用，不用装进虚拟机。

隐私

声音去哪儿，说清楚

MicMask 没有变声服务器。完整说明见 App 内「关于 → 其他 → 隐私说明」。

录音只在本机推理

录音和模型推理都在你的手机上完成，音频不上传任何服务器，也不经过中转。

匿名统计可以关

首次打开时由你选择是否参与匿名统计，之后随时可在设置里关闭。基础统计不含机型信息。

模型来源与授权自负

第三方音色模型的来源、授权和相关声音权利，请使用者自行确认，勿用于违法用途。

日志只在你导出时打包

日志不会自动上传。需要反馈时由你在 App 里导出，自己决定发给谁。

    常见问题

    需要 ROOT 吗？

    不需要。MicMask 借助 Shizuku 拿到的 shell 权限工作，手机无需解锁 Bootloader 或刷机。

    对手机有什么要求？

    64 位 Android 手机，安装需要 Android 8.0 及以上，Shizuku 注入模式需要 Android 10 及以上。AI 实时变声对 CPU 要求较高：骁龙 8 Gen 3 等旗舰可以跑标准档，中端芯片建议用省电档 0.5 秒。

    需要把 QQ 装进虚拟机吗？

    不需要。原应用直接使用，MicMask 自动识别正在录音的目标应用并接管麦克风。

    收费吗？

    免费，并且以 GPL-3.0 协议开源。赞助完全自愿，不影响任何功能。

    会上传我的声音吗？

    不会。全部为本地推理，音频不离开你的手机。

    没有 Shizuku 能用吗？

    可以用普通模式（外放 / 录播回退），但效果有限，实时通话场景仍建议配合 Shizuku。

    怎么反馈问题？

    在 App 的日志页导出日志，加 QQ 群 780988679，或到 GitHub Issues 提交，附上日志更好定位问题。
