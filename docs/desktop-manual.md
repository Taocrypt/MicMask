# MicMask 电脑版使用手册（Windows）

MicMask 电脑版和手机上的 MicMask 互传声音：

- **手机 → 电脑**：把手机的声音（手机麦克风、手机上变声后的声音）收进电脑，当电脑的麦克风用（配合 VB-CABLE）。
- **电脑 → 手机**：把电脑的声音（电脑麦克风、某个程序的声音，例如 RVC / w-okada 变声后的输出）发到手机，手机再注入到 QQ / 微信 / 游戏。

两边用同一套加密协议（MicMask Link v1：SPAKE2 配对码 + AES-GCM），同一 Wi-Fi、USB、热点、异地组网（EasyTier / Tailscale / ZeroTier）都能用。

> 电脑版目前是测试版（版本号 `0.x`，标签 `win-v…`）。遇到问题请先「导出日志」再反馈。

---

## 1. 安装

1. 到 GitHub Release 下载电脑版（标签以 `win-v` 开头，标记为「预发布」）：
   - `MicMask-<版本>-windows-x64.msi`（推荐）或 `MicMask-<版本>-windows-x64-setup.exe`。
   - `SHA256SUMS.txt` 可用来核对文件完整。
2. 双击安装。系统要求：Windows 10 / 11 64 位。「按应用抓声音」需要 Windows 10 2004（19041）或更新。
3. **首次安装出现 SmartScreen**（「Windows 已保护你的电脑 / 未知发布者」）：点「更多信息」→「仍要运行」（电脑版暂未代码签名）。签名状态见 Release 说明。
4. 第一次「接收」时 Windows 防火墙会询问是否允许 MicMask 访问网络：勾选「专用网络」并允许（用公用网络 / 组网时也勾上「公用网络」）。

升级：直接装新版 MSI / EXE 会自动卸载旧版再安装，设置和已保存设备保留（存在 `%APPDATA%\MicMask`），也可以在「关于」页点「下载并安装」。
「应用和功能」里显示的是安装包数字版本（如 0.1.0-alpha.3 显示为 0.1.103），程序「关于」页显示完整版本号。
**从 0.1.0-alpha.1 升级到 0.1.0-alpha.2 装不上**（安装提示一闪而过、打开还是旧版）是这两版安装包版本号相同导致的，装 alpha.3 及以后的版本即可直接覆盖升级，不需要先卸载。

## 2. VB-CABLE（虚拟麦克风）

要把手机的声音当成电脑麦克风，需要一条「虚拟线」：

- 播放端 **CABLE Input**：MicMask 把收到的声音播放到这里；
- 录音端 **CABLE Output**：聊天软件 / 游戏 / OBS 里把麦克风选成它。

安装：传音页右侧「虚拟麦克风（VB-CABLE）」→「一键安装 VB-CABLE」（需要管理员权限，在弹出的确认里点「是」），装完**重启电脑**。
安装包里附带的是 VB-Audio 官方驱动包原件（捐赠软件，欢迎到 vb-cable.com 支持作者）。

已经装了 Voicemeeter 的用户也可以把「播放到」选成 Voicemeeter Input，再在 Voicemeeter 里路由。

## 3. 手机 → 电脑（手机当电脑麦克风）

1. 电脑：传音页右侧打开「接收手机的声音」，「播放到」选 **CABLE Input**（默认会自动选它）。
2. 手机：MicMask「传音」页 → 发送 → 连接这台电脑，三种方式任选：
   - **扫码**：电脑「接收」卡里显示二维码，手机点扫码，扫完即连（二维码里有电脑的所有地址和配对码）。
   - **自动发现**：同一 Wi-Fi 下手机列表里会出现「MicMask-PC-电脑名」，点它，输入电脑上显示的 6 位配对码。
   - **手动**：输入电脑「接收」卡里列出的 IP（端口 47310）和配对码。
3. 电脑上「来自 …」下面会显示包数、丢包、抖动、缓冲、传输方式（UDP / TCP）等；聊天软件里把麦克风选成 **CABLE Output**。

提示：
- 配对码可以复制、可以「换一个」（手机连着时不能换）。二维码含配对码，别发给不认识的人。
- 缓冲会自动适应网络：UDP 一般 30–80 ms；只能走 TCP 的组网会自动加大到 60–250 ms，避免断音。

## 4. 电脑 → 手机（电脑声音发到手机）

1. 手机：MicMask「传音」页打开「接收」（要注入 QQ / 微信 / 游戏需要 Shizuku / ROOT / 系统权限模式）。
2. 电脑：传音页左侧「发送」卡：
   - **输入通道**：系统默认录音设备、电脑麦克风、耳机麦克风、任一录音设备（带 内置 / USB / 蓝牙 / 虚拟声卡 / 默认 标记）、**某个应用的声音**、**电脑播放的所有声音**，或「手机麦克风」（把收到的手机声音再转发出去）。
   - **输入增益**：−12 ~ +24 dB；**自动增益**（AGC，目标约 −18 dBFS，带限幅不会爆音）适合声音忽大忽小或偏小的情况。电平表显示的是增益后的电平，最好在说话时落在 −30 ~ −10 dBFS。
   - **编码**：跟随手机（默认）/ Opus（省流量、抗丢包）/ PCM（无压缩，USB / 热点直连时用）。
3. 在「手机」卡里连接手机：
   - 列表里点扫描到的手机（第一次要输入手机「接收」页的配对码，之后自动记住）；
   - 或者**粘贴手机分享的 `micmask://link?…` 链接**（手机「接收」页的链接 / 二维码内容），点「导入并连接」；剪贴板里有链接时会提示一键导入；
   - 或者手动输入手机 IP 和配对码。
4. 「自动连接」（默认开）：已保存的手机出现时自动连接发送，断线自动重连；手动点「停止发送」后不再自动连，直到再手动连一次。

### 同时收和发（双向）

电脑同时开「接收」和「发送」到**同一台手机**时，电脑会优先复用同一条连接双向收发（界面显示「双向：同一条连接」），不会两条连接互相抢。停止发送不影响接收。手机端需要较新的版本；旧版手机会自动退回到两条连接。

## 5. 按应用抓声音（不占用 VB-CABLE）

适合「电脑上用 RVC / w-okada 变声 → 发到手机」：

1. 先让那个程序开始出声（例如 RVC 开始实时变声；它的输出设备选任意扬声器 / 耳机即可，不需要选 VB-CABLE）。
2. 「发送」卡 → 输入通道 → 选「应用：xxx」（正在出声的程序排在前面，3 秒刷新一次；常见程序会标注 RVC / w-okada / OBS / Python）。
3. 「抓取范围」：
   - **只抓这个程序**（含它启动的子进程）——推荐；
   - **抓除这个程序以外的所有声音**——例如抓游戏 + 音乐，但不要语音软件本身的声音。
4. 另有「电脑播放的所有声音（除 MicMask）」，相当于系统内录。

要求 Windows 10 2004 及以上，并且「设置 › 低延迟音频引擎（WASAPI）」开着。抓不到时界面会写原因（程序还没出声、系统版本太旧等）。

## 6. 音频引擎

- 默认用 **WASAPI 共享模式**（随安装包的 mmaudio.dll），延迟更低，并支持按应用抓声音。
- 某个设备用 WASAPI 打不开时，自动回退到 **DirectSound**（兼容模式），日志里会记录原因。
- 遇到兼容问题可以在「设置」里关掉「低延迟音频引擎」，只用 DirectSound。
- 多声道设备（如 Voicemeeter VAIO 8 声道）下混时只平均有信号的声道，不会把声音平均小。

## 7. 托盘

- 点窗口关闭按钮默认**最小化到托盘**（第一次会问一次，设置里可改成直接退出 / 每次询问），收发、自动连接在后台继续。默认只隐藏窗口（恢复即时）；「设置 › 缩到托盘时释放窗口」打开后会销毁窗口，更省内存，恢复稍慢。
- MicMask 只运行一个：再次双击图标会把已运行的窗口调到最前（也会从托盘恢复）。
- 单击 / 双击托盘图标打开窗口；右键菜单：显示主窗口、开始/停止接收、开始/停止发送（发给最近连过的手机）、导出日志、退出。
- 启动参数 `--tray`：开机直接在托盘里运行；「启动时恢复接收」（默认开）。

## 8. 日志与反馈

- 日志位置：`%LOCALAPPDATA%\MicMask\logs`（按天保存，保留最近 7 个文件、最多 20 MB）。
- 「导出日志」（日志页 / 设置页 / 托盘菜单）：先填「标题」（作为文件名，可留空）和「遇到的具体问题」，生成 `标题.zip`（留空时为 `micmask-desktop-logs-时间.zip`）放到桌面并在资源管理器里选中，包含问题描述 report.txt、日志和系统信息（Windows / Java 版本、音频设备、网卡地址、版本号、设置项），配对码和密钥不会写入。
- 反馈时请附上：电脑端导出的 zip、同一时段手机端的日志、所选的输入通道 / 播放设备、网络方式（同一 Wi-Fi / 组网名称）。
- 日志每 10 秒记录：接收（包数、丢包、抖动、缓冲、UDP/TCP、最大到达间隔、心跳超时、断流、漂移裁剪、电平），发送（增益前/后电平、AGC、限幅、音频引擎、手机缓冲、对端延迟）。

## 9. 远程组网（EasyTier / Tailscale / ZeroTier）

- 电脑「接收」监听 `0.0.0.0:47310`（TCP + UDP，所有网卡，包括虚拟网卡）；「接收」卡里列出所有地址，组网虚拟网卡会单独标注，二维码也包含这些地址。
- 组网下 mDNS 扫不到对方，请用**扫码 / 粘贴链接 / 手动 IP**。
- 音频优先走 UDP；UDP 不通时自动走 TCP，并持续低频探测，通了自动切回 UDP。走 TCP 时接收缓冲会自动加大、心跳超时放宽（按 RTT 自适应，至少 10 秒），偶发的延迟尖峰不会断线。
- 某些组网（EasyTier 的 TCP 代理、Tailscale userspace 模式）会改变 TCP 的来源地址，新版已兼容，UDP 也能打通。
- 防火墙：确认 Windows 防火墙对 MicMask 放行了对应的网络类型（组网网卡常被识别为「公用网络」）。

## 10. 统计、公告、赞赏

- 电脑版和手机版用同一个后台：公告、赞赏墙；匿名使用统计需要你同意（首次启动询问，设置里随时关），只含随机安装 ID、版本、Windows 版本、功能使用次数和崩溃类名，不含声音、设备名、IP、配对码。
- 构建时没有配置后台的版本（例如自己编译的）不会发出任何统计请求，公告 / 赞赏墙显示「未启用」。
- 维护者：电脑版与手机共用同一 Beacon App 和 key；后台把该 App 的「平台（可多选）」勾上 Windows，只给安卓的公告在条件里设渠道（见 `docs/desktop-signing.md`）。
- 「关于」页：检查更新（只看电脑版 `win-v` 标签）、本手册、问题反馈、赞赏墙、赞赏作者。

## 11. 常见问题

**手机扫不到电脑 / 电脑扫不到手机**：确认在同一 Wi-Fi、路由器没开「AP 隔离」；访客网络通常互相隔离。组网请用扫码 / 链接 / 手动 IP。

**连接超时 / 被拒绝**：对方没打开「接收」、IP 填错，或被防火墙拦截。电脑端看「接收」卡里的地址；手机端看「接收」页的地址。

**配对码不对 / 被锁定**：配对码错 5 次会锁 1 分钟，稍后再试。手机或电脑「换一个」配对码后，已保存设备会提示重新输入。

**连上了但没声音（手机 → 电脑）**：「来自 …」下电平是否在跳；聊天软件里麦克风要选 **CABLE Output**，不是 CABLE Input；手机端是否在说话 / 没静音。

**连上了但没声音（电脑 → 手机）**：发送卡电平表是否在跳；3 秒没信号会提示「可能选到了静音设备」；选 Voicemeeter / 虚拟线时要确认真的有程序往那条线播放。状态里出现「手机没在收」说明手机没打开「接收」。

**声音小 / 忽大忽小**：调「输入增益」或打开「自动增益」；新版已修复多声道虚拟声卡被平均变小的问题。

**断断续续 / 延迟变大**：看日志里的传输方式和「最大到达间隔」；组网只能走 TCP 时缓冲会自动加大；尽量让两端走同一 Wi-Fi 或打通 UDP。

**按应用抓声音列表里没有我的程序**：程序要先开始出声；系统需 Windows 10 2004+；设置里「低延迟音频引擎」要开着。

**安装时提示「Windows 已保护你的电脑」（SmartScreen）**：点「更多信息」→「仍要运行」。电脑版暂未代码签名，这是正常提示。

**关闭窗口后程序还在**：在托盘里继续运行（收发不中断）。右键托盘图标 →「退出 MicMask」才是真正退出。

**内存占用**：正常收发约 200 MB 左右（Java 运行时 + 界面）；关到托盘会降低；「设置 › 界面渲染 › 软件渲染」可再省约 30 MB。
