## 简介

MicMask 是一款安卓端的**原生实时 AI 变声软件**。它在手机本地把你的声音实时转换成另一个音色，并直接送进 QQ、微信、游戏等应用的麦克风，对方听到的就是变声后的声音。

主要特点：

- **无需 Root**：借助 [Shizuku](https://shizuku.rikka.app/) 以 shell 身份把声音注入其他应用的麦克风。
- **不用虚拟机或双开容器**：目标应用正常安装、正常打开即可。
- **真正的本地 AI 推理**：基于 RVC 音色转换，ONNX Runtime 在手机 CPU 上运行，录音不上传任何服务器。
- **低延迟**：骁龙 8 Gen 3 实测端到端约 300 ms（标准档）。
- **免费开源**：GPL-3.0 协议，源码公开在 GitHub。

除了 AI 实时变声，MicMask 还提供普通变声（升降调 + 音色效果）、虚拟声卡、音效包送麦、文件变声和文字转语音。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| Android 版本 | 安装需要 Android 8.0 及以上；**Shizuku 注入模式需要 Android 10 及以上** |
| 处理器架构 | 仅支持 **arm64-v8a**（64 位 ARM），不支持 32 位手机和 x86 模拟器 |
| 推荐芯片 | AI 实时变声对 CPU 要求较高。作者实测设备为骁龙 8 Gen 3（标准档 0.3 秒稳定运行）；同级旗舰芯片通常可以跑标准档，中端芯片建议使用省电档 0.5 秒 |
| 存储空间 | 安装包约几十 MB；每个音色另需数十 MB；文件变声句级模型约 75 MB；文字转语音模型需单独下载 |
| 其他 | 实时注入需要安装并启动 Shizuku；建议佩戴耳机 |

> 2.1 测试版起，骁龙平台可以把声码器和 HuBERT 交给 NPU 加速（见[高级参数](#高级参数)）；其他芯片只用 CPU。不使用 GPU。

## 安装与更新

### 下载安装

1. 打开 [GitHub Releases](https://github.com/Taocrypt/MicMask/releases/latest)。
2. 下载名为 `MicMask-<版本>-android-arm64-v8a.apk` 的文件。
3. 在手机上打开 APK 安装。系统提示「未知来源」时，按提示允许浏览器或文件管理器安装应用。

### 应用内更新

打开 **设置 → 其他 → 关于 MicMask**：

- **检查更新**：点一下立即检查，有新版本会显示更新内容，下载完成后点「点此安装」。
- **接收测试版**：打开后 alpha / beta / rc 测试版和正式版都会推送，新功能先到但可能不稳定；关闭则只推送正式版。
- **启动时检查**：关闭后仍会检查强制更新。
- **下载镜像**：GitHub 连不上时会自动测速选择镜像，也可以在这里手动添加镜像。

### 升级注意

- 覆盖安装即可升级，音色、预设、设置都会保留。
- 升级后如果实时变声表现异常，先在 Shizuku 模式下停止变声再重新开始（新版本会重启注入服务）。

## 两种运行模式

在 **设置 → 运行模式** 中切换。变声进行中不能切换，需先关闭变声。

### Shizuku 模式（推荐）

把变声直接送进目标应用的麦克风，支持**实时 AI 变声、普通变声和虚拟声卡**。不需要 Root。

准备步骤：

1. 安装 Shizuku：从 [Shizuku 官网](https://shizuku.rikka.app/) 或应用商店下载。
2. 启动 Shizuku：
   - **Android 11 及以上**：在开发者选项中打开「无线调试」，在 Shizuku 里选择「通过无线调试启动」，按提示配对。
   - **Android 10**：需要连接电脑，用 adb 执行 Shizuku 给出的启动命令。
   - 已 Root 的手机也可以直接用 Root 启动 Shizuku。
3. 回到 MicMask，点 **设置 → 运行模式 → Shizuku 模式**，在弹出的 Shizuku 授权框中选择允许。

> Shizuku 用无线调试启动后，**手机重启需要重新启动 Shizuku**。部分系统关闭 WLAN 或断开无线调试后也会停止，需要重新启动。

### 普通模式（无需授权）

不使用 Shizuku。变声和音效从**扬声器外放**：

- AI 变声和普通变声变成「**录一句再放**」的录播方式：按住按钮录一句，松手自动转换并从扬声器播放。悬浮窗里也能按住录音。
- 虚拟声卡不可用。
- 因为是外放，**对方可能同时听到你的原声**。适合没有条件使用 Shizuku 时临时使用。

## 首次使用流程

1. **同意使用说明**：首次打开会弹出信息收集说明与免责声明，阅读后同意（可选择是否参与匿名统计）。
2. **授予麦克风权限**：开始变声或录音时，按系统提示允许录音。
3. **选择运行模式**：按上一节准备 Shizuku 并授权；暂时没有 Shizuku 就用普通模式。
4. **获取音色**：
   - 在 **设置 → 模型仓库** 点「添加仓库」，填写你信任的仓库地址（支持 models.json 链接、GitHub 仓库主页或 CNB 仓库地址）。
   - 回到底栏 **变声 → AI 变声**，在「模型仓库」列表里下载一个音色；或点「导入模型」导入手机里的模型（见[导入音色](#导入音色)）。
5. **设置生效范围**：**设置 → 变声设置 → 生效范围**，默认「自动识别」即可。
6. **开始变声**：在 **变声 → AI 变声** 选中音色，点顶部卡片的「开始」。
7. **试听**：开始变声后，按住「按住 录制预览」录一段，松手回放，确认效果；也可以打开「实时耳返」用耳机监听。

## AI 实时变声

位置：底栏 **变声** → 顶部切换到 **AI 变声**。

### 下载音色与模型仓库

- 页面下方「模型仓库」列出已添加仓库中的音色，可按「男声 / 女声 / 动漫 / 其他」分类、搜索、按仓库筛选。点击下载即可，下载完会出现在「本地音色」中。
- 仓库在 **设置 → 模型仓库** 管理：
  - 「添加仓库」：填写备注名（可空）和仓库地址或 models.json 链接。
  - 按住 ⋮⋮ 拖动排序，靠上的仓库优先；点一项可改备注名或删除；右侧开关启用/停用。
  - 「刷新全部」重新获取清单。
- 仓库由社区维护，请只添加你信任、有权使用的仓库。

### 本地音色

- 点一个音色即选中；**变声进行中也可以直接切换音色**，状态行会显示「正在切换到 X…」，切换完成后生效。
- 按住左侧 ⋮⋮ 拖动排序；更多操作有「置顶 / 取消置顶」「编辑」（改显示名称）「删除」。
- 带「兼容模式」标记的音色是直接导入的 w-okada 格式 ONNX，速度较慢（见[导入音色](#导入音色)）。
- 「性能测试」按钮：约 1–2 分钟，实测本机后自动采用：档位设为自动，声码器（ORT / NEON / NPU）和 HuBERT 后端取最快，再试几组特征 / 合成线程数取最稳的一组，结束后弹窗显示采用了哪些设置。测试时不要切到后台。

### 音高偏移（半音）

滑杆范围 -12 ～ +12 半音，提供三个快捷按钮：

| 按钮 | 值 | 适合 |
| --- | --- | --- |
| 男声→女声 | +12 | 男声用女声音色。偏低沉可 +12，偏尖可回到 +10 |
| 同性别 | 0 | 你的声音与音色同性别。偏闷或偏尖时 ±1～3 微调 |
| 女声→男声 | -12 | 女声用男声音色 |

+4 ～ +9 介于两者之间，适合中性声线或想要少年 / 低沉女声的效果。

### 音量增益

对方听着太小声就调高；声音发炸、破音就调低。开着变声也能实时调，点「重置」恢复。

### 高级参数

点「高级 展开 ▾」。修改过的项目会显示「已自定义」，「恢复默认」一键还原。

**档位**

| 档位 | 说明 |
| --- | --- |
| 自动（默认） | 按测速选能跑稳的最低延迟档，频繁断音时自动降到省电档 |
| 标准 0.3s | 延迟最低；手机跟不上会断音，且**不会自动降档** |
| 省电 0.5s | 延迟多约 0.2 秒，算力省约 40%，发热少 |

> 自动降档：在「自动」档下，如果推理持续跟不上（例如手机发热降频、App 被切到后台导致 CPU 降频），会自动切到省电 0.5s 档以避免断音。

**静音门限**：低于它的声音不送进模型（省电、去底噪）。默认 -50。开头的字被吞就调低，环境吵、有杂音就调高。

**检索比例（index）**：0 为关闭，默认 0.3。越高越像原音色、口音和原声漏出越少，但咬字可能变糊。只有导入时带了 `.index` 检索索引的音色才能调；没有索引会提示「当前音色没有检索索引」。

**特征线程 / 合成线程**：两段推理同时在跑，两者加起来不要超过大核数，默认 3 / 4。改档位或线程会重新测速加载，变声中会停顿几秒。

**推理绑大核**（默认开）：把推理线程固定在大核上，减少被调度到小核导致的卡顿；下次开始变声生效。

**声码器**：合成器最后一段的运行方式。

| 选项 | 说明 |
| --- | --- |
| 自动（默认） | 实测几种方式，取最快的 |
| ORT | 整图用 ONNX Runtime 在 CPU 上跑，兼容性最好 |
| NEON | 原生 fp16 内核，需要 CPU 支持 ARMv8.2 半精度指令 |
| NPU | 交给骁龙 NPU；每个音色首次使用要编译约 10 秒，出错自动改用 CPU。只在骁龙平台显示 |

**HuBERT 用 NPU**（默认关）：内容特征提取交给骁龙 NPU。首次使用要改写并编译模型；不比 CPU 快或校验不通过会自动留在 CPU。

**NPU 组件**：NPU 加速需要高通 QNN 运行库。它按高通自己的许可发布，不属于 MicMask 的开源部分，也不随安装包分发；首次开启时会弹出高通许可，同意后 App 从 Maven Central 或其国内镜像下载官方包并逐个校验，支持断点续传。

**响度跟随**（实验，默认关）：让变声后的音量起伏跟着原声走，轻声说话也轻。0 为关，越高越贴原声；拉高后整体音量可能变小，可配合音量增益。

**共振峰**（实验，默认 0）：音高不变，只改声音厚薄。往右更细更亮，往左更厚更沉，范围 ±6。拖动即时生效，不用重新加载。

**相位锁定**（实验，默认关）：让每段合成的声音首尾相位接上，减轻块与块之间的轻微「嗒嗒」声。切换会重新加载模型；每个音色首次开启会在本机改写一次模型。

### 生效范围

位置：**设置 → 变声设置 → 生效范围**（变声中不可修改）。

- **自动识别**（新装默认）：任何应用开始录音（语音通话、语音消息、游戏语音、语音识别等）都会变声，不用选应用。MicMask 自己的录音会被排除。
- **手动选择**：只对选中的「目标应用」变声。点「目标应用」进入列表勾选，可搜索、按名称/安装时间排序、显示系统应用。未选择任何应用时只做本机试听。

### 变声设置里的其他开关

位置：**设置 → 变声设置**。

- **降噪模式**：开 = 回声消除 + 降噪（通话录音）；关 = 原始麦克风，音质优先。变声中切换会重启变声。
- **实时耳返**：把变声后的声音送到耳机。**外放会啸叫，请戴耳机**。
- **兼容录音**：部分机型 MicMask 的录音会失败，此时会自动启用兼容录音；打开这个开关则始终使用兼容方式。遇到「开始变声后没有麦克风数据」可以试试。
- **悬浮窗开关**：见[悬浮窗](#悬浮窗)。

## 导入音色

MicMask **不附带任何音色模型**。获取方式有三种：

### 1. 从模型仓库下载（推荐）

见上一节。仓库里的音色已经转换成适合手机实时推理的流式格式，下载即用，速度最快。

### 2. 手机直接导入 RVC .pth（可带 .index）

适合你手里只有 RVC 训练产出的 `.pth`（和 `.index`）文件的情况。

1. 把 `.pth` 和对应的 `.index` 文件放到手机里。
2. 在 **变声 → AI 变声** 点「导入模型」，在文件选择器里**同时选中 `.pth` 和 `.index`**（长按多选）。
3. App 会在本机生成「标准档」和「省电档」两个实时音色，并把 `.index` 转成精简检索索引。一般需要几十秒到一两分钟，期间不要退出。

也可以在 QQ / 微信 / 文件管理器里对 `.pth` 文件用「分享」或「打开方式」选择 MicMask 导入。

支持范围与限制：

- 支持 RVC v1 / v2，32k / 40k / 48k 采样率，**必须是带音高（f0）的模型**。
- 无音高模型、非常规结构（如自定义上采样率）会提示不支持。
- 旧版（非 zip 格式）的 `.pth` 需要先在电脑上用新版 PyTorch 重新保存。
- 没带 `.index` 也能用，只是「检索比例」不可调。单独导入 `.index` 时，文件名要包含音色名，App 才知道它属于哪个音色。

### 3. 导入模型 zip 或 ONNX

- **模型 zip / 流式 .onnx**：用项目自带的 `tools/convert_rvc.py` 在电脑上转换出的流式模型（文件名形如 `<音色>_stream_qdq.onnx`、`<音色>_stream_b50_qdq.onnx`），打包成 zip 或直接选中导入。这是最快、最推荐的格式。
- **兼容 ONNX**：w-okada voice-changer 导出的 RVC ONNX 也能直接导入，音色会带「兼容模式」标记。它是整段推理的原版模型，**比流式版慢很多**：录播变声可用，实时只建议高性能手机。建议用 `convert_rvc.py` 转成流式版。

| 方式 | 速度 | 检索（index） | 推荐程度 |
| --- | --- | --- | --- |
| 仓库下载 | 最快 | 视仓库提供 | ★★★ |
| 手机导入 .pth (+ .index) | 快（本机量化） | 支持 | ★★★ |
| 电脑转换的流式 zip / .onnx | 最快 | 视转换时是否附带 | ★★ |
| 兼容 ONNX（w-okada） | 慢 | 不支持 | ★ |

> 请只导入你本人的声音或已获得授权的模型，详见[免责声明与模型授权](#免责声明与模型授权)。

## 普通变声与声卡

### 普通变声

位置：底栏 **变声** → 顶部切换到 **普通变声**。低延迟的升降调加音色效果，不需要 AI 模型，对手机性能要求低。

- **声线预设**：原声、男变女、萝莉、御姐、女变男、大叔、怪兽、机器人、电话音。可切换「▦ 网格 / ☰ 列表」显示。
- **音调与音量**：音调（半音）与音量增益。
- **音色**：厚度（低频）、清晰度（中频）、明亮度（高频）、去闷（低切）、沙哑（激励）、空间感（混响）、底噪抑制（噪声门）。
- **保存为预设**：把当前参数存成自己的预设（★）。长按 ★ 预设可分享、重命名、删除；分享码以 `MICMASK-PRESET:` 开头，可以直接贴进聊天发给朋友，对方点「导入」即可。同名预设会自动加 (2)(3)。

这些参数只作用于普通变声模式，和声卡、AI 变声互不影响。

### 虚拟声卡

位置：底栏 **变声** → 顶部切换到 **虚拟声卡**。**需要 Shizuku 模式**。提供场景预设、空间、动态、均衡 / 总线等旋钮推子，适合唱歌、直播等场景。双击旋钮或推子复位。耳返开关在设置里，外放会啸叫，请戴耳机。

## 悬浮窗

打开：**设置 → 变声设置 → 悬浮窗开关**（首次需要授予「悬浮窗 / 显示在其他应用上层」权限）。

- **单击**悬浮球展开控制窗：切换模式（AI / 普通 / 声卡）、选预设、看性能；**双击**打开 App；**长按**关闭悬浮窗。
- 点模式按钮启动，再点一次停止；拖动悬浮球可贴边。
- 控制窗里可以快速开关「耳返」「降噪」，播放音效包和本地音频（点素材即送麦），并显示电池温度、内存、断流次数等。
- 控制窗右下角「⤡」长按后拖动，可自由调宽和高；双击「⤡」恢复默认大小。
- 外观设置（悬浮窗开关打开后显示）：悬浮球大小、悬浮球不透明度、控制窗内容缩放、控制窗不透明度、「收起后自动贴边半隐藏」（3 秒不操作，悬浮球缩进屏幕边缘一半），「恢复默认」一键还原。
- 普通模式下，悬浮窗里也能按住录一句，松手转换后外放。

## 文件变声、文字转语音与音效包

### 文件变声

位置：**变声 → AI 变声** 页底部「更多 → 文件变声」。把一段音频整段转换，基于 RVC 合成，音质比实时变声更好。

1. **句级模型**：首次使用需要「在线下载句级模型」（约 75 MB，合成器 + 检索索引）或「从手机导入模型」（zip 或 .onnx / .bin），然后点「加载模型」。加载一次会一直留在内存，再点可释放内存。
2. **输入**：「选择音频」（支持 wav / mp3 / m4a / flac / ogg）或直接「录音」；也可以从 QQ / 微信 / 文件管理器「分享」音频给 MicMask。录过和导入过的音频会保存在「历史录音」中。QQ / 微信的 SILK 语音会被识别并提示先转码。
3. **参数**：变调（男声转女声一般 +8 ～ +12）、音色检索（更像目标音色，慢一点）、检索混合比例、无声段保护（默认 0.33）。「高级参数」里有说话人 ID、拼接重叠、推理线程，不熟悉保持默认。
4. 点「开始变声」。长音频会自动在最安静处分段处理，通知栏显示进度，可随时「取消转换」。
5. **结果**：试听、导出（存进「音乐/MicMask」，可选 WAV 或 M4A）、加入音效包、设为待发送、送麦。最近的结果保存在「历史结果」中。

不需要文件变声时，可以「删除句级模型」释放空间，实时变声共用的特征 / 音高模型会保留。

### 文字转语音

位置：「更多 → 文字转语音」。输入文字合成语音，基于 GPT-SoVITS，全部在手机上计算，一句要几十秒。

- 首次使用需要从仓库下载合成模型（只下缺的文件）或从手机导入。
- **仅支持中文**，英文和数字会被忽略。
- 可选「语气」（每种语气配了一段参考原声，模仿它的起伏和节奏）和「语速」；高级参数有采样温度、Top-K、Top-P、重复惩罚，默认值最稳。
- 合成结果可试听、送麦；用过的会进入「常用语音」，少用的自动清理。

### 音效包与本地音频

位置：底栏 **语音**。

- **音效包**：内置 9 个预设音效（CC0 授权）。「添加音效」支持 mp3、m4a、wav、ogg、flac 等常见音频，可自选分组；「导入音效包」导入别人分享的 `.mim3`；「制作音效包」把手机里的音频打包成 `.mim3`（保存到 `Download/MicMask/<分组名>.mim3`）；每个分组标题右侧「导出音效包」可打包分享。
- **本地音频**：导入手机里的音乐或录音。
- **仓库素材**：模型仓库清单里提供的音效，可直接下载。
- 点卡片试听（扬声器），点「送麦」播给对方。送麦会叠加在变声之后；没在变声时会自动用声卡模式打开麦克风通道。可调音量、「送麦时循环」，「全部停止」一键停止。
- 长按素材进入多选，可删除、重命名。

> 普通模式下没有麦克风注入，音效会从扬声器外放。

## 在 QQ / 微信 / 游戏中使用

以 Shizuku 模式为例：

1. 确认 Shizuku 正在运行，MicMask 的运行模式为「Shizuku 模式」且显示「已授权」。
2. 生效范围保持「自动识别」；或选「手动选择」并在「目标应用」里勾选 QQ / 微信 / 游戏。
3. 在 MicMask 里选好音色，点「开始」。建议同时打开悬浮窗，方便在其他应用里切换和停止。
4. 切到 QQ / 微信 / 游戏，正常发起语音通话、发语音消息或打开游戏内语音。对方听到的就是变声后的声音。
5. 想听自己变声后的效果，戴上耳机并打开「实时耳返」。
6. 用完后在悬浮窗或 App 里点「停止」。如果停止后某个应用没有声音，见[常见问题](#常见问题与排查)。

小贴士：

- 游戏或通话里感觉延迟大，可以在 AI 高级参数里尝试「标准 0.3s」档（前提是手机跑得动）。
- 对方说声音小或破音，用「音量增益」调整。
- 觉得音质发闷，可以在 设置 → 变声设置 里关闭「降噪模式」试试（改用原始麦克风）。

普通模式下：按住「按住 录一句」录音，松手转换后从扬声器外放，需要把手机靠近另一台设备或在通话中外放，对方会同时听到原声，效果有限。

## 性能状态行怎么看

AI 实时变声运行时，顶部卡片会显示一行性能摘要，例如：

```text
延迟约 420 ms · 推理 166 ms · 实时率 0.55
```

| 字段 | 含义 |
| --- | --- |
| 延迟约 | 估计总延迟 = 块长 + 端到端 + 输出缓冲 |
| 推理 | 特征提取和音色合成中较慢那一段的耗时 |
| 实时率 | 较慢一段 ÷ 块长。**接近 1 会断音**，超过 0.9 时会显示 ⚠ |

点一下状态行可以展开明细：

- **特征 X / Y ms（中位/p95）**：HuBERT 特征提取 + 音高提取（含检索）的耗时。
- **合成 X / Y ms（中位/p95）**：音色合成器的耗时。
- **端到端 X / Y ms · 块长 Z ms**：一块音频从录到推理完成的时间。骁龙 8 Gen 3 标准档实测约 300 ms。
- **超预算 / 丢块 / 静音块**：推理超过块长的块数、被丢弃的块数、低于静音门限被跳过的块数。
- **输出缓冲 / 断流 / 麦电平 / 目标在录**：输出队列长度、断流次数、麦克风电平、正在录音的目标应用数。

没有说话时显示「等待说话… · 块长 X ms」。

判断方法：

- 实时率长期 > 0.9、断流持续增加 → 改用省电 0.5s 档，或减少后台应用、给手机降温。
- 「超预算」告警只在特征或合成单段超过块长、或端到端超过 2 倍块长时出现，5 秒内最多一条。

## 常见问题与排查

### 停止变声后某个应用没有声音

点 **设置 → 其他 → 音频还原**（「应用没声音时点这里还原」）。它会停掉注入、还原真实麦克风，并把被设为禁止的 `PLAY_AUDIO` 权限改回允许。

> 日志中出现「`PLAY_AUDIO` 被设为禁止」时，说明某个应用的播放权限被系统或其他工具禁用了（**不是 MicMask 写的**），用「音频还原」即可一键恢复。

### 开始变声后对方听不到 / 听到原声

- 确认运行模式是 Shizuku 模式且已授权，Shizuku 仍在运行（重启手机后需要重新启动 Shizuku）。
- 生效范围选「手动选择」时，确认目标应用已勾选。
- 先开始变声，再在目标应用里发起通话；已经在通话中的，挂断重拨一次。
- 状态行出现麦克风提示（没有收到麦克风数据、纯静音、被系统静音）时，试试打开「兼容录音」。
- 部分机型的系统不支持注入，可以导出日志反馈。

### 啸叫、回声

- 外放时扬声器的声音会被麦克风再录进去，产生啸叫。**请佩戴耳机**，或关闭「实时耳返」。
- 打开「降噪模式」（回声消除）可以减轻回声。

### 普通模式下对方听到原声（录播泄漏）

普通模式只能从扬声器外放变声结果，目标应用的麦克风仍然录到你的原声。这是普通模式的固有限制，要完全替换原声请使用 Shizuku 模式。

### 断音、卡顿、延迟变大

- 看状态行的实时率，跟不上就用省电 0.5s 档，或保持「自动」档让它自动降档。
- 保持「推理绑大核」开启；线程数保持默认 3 / 4。
- 手机发热严重时 CPU 会降频，可以摘掉手机壳、降低屏幕亮度。
- 把 MicMask 切到后台时，部分系统会给它降频，合成耗时明显增加，可能触发自动降档。

### 后台运行一段时间后变声停止

部分系统（ROM）会回收后台应用。请在系统设置里为 **MicMask 和 Shizuku** 都：

- 允许自启动 / 关联启动；
- 电池优化设为「不限制」或「允许后台高耗电」；
- 在最近任务里锁定 MicMask。

### 开头的字被吞

把高级参数里的「静音门限」调低（例如 -55 ～ -60）。

### 导入 .pth 失败

- 确认是带音高（f0）的 RVC v1 / v2 模型，采样率 32k / 40k / 48k。
- 旧版 `.pth` 需要在电脑上用新版 PyTorch 重新保存。
- 错误信息会显示在导入结果提示中，也会写进日志。

### 已知限制

- 仅支持 arm64 手机；AI 实时变声对 CPU 要求高，中低端机可能只能跑省电档。
- 量化模型相对电脑端有一定音质损失。
- 部分机型或系统版本的音频策略不支持注入，实时变声不可用（可用普通模式）。
- 外放场景容易啸叫，请戴耳机。
- 无线调试启动的 Shizuku 在重启手机后需要重新启动。
- 早期测试版（2.0-alpha7 之前）使用的是旧包名，与现在的 `com.taocrypt.micmask` 不是同一个应用，无法覆盖升级，需要卸载旧版重新安装，旧版的数据不会保留。

## 导出日志与反馈

遇到问题时，日志能帮助快速定位。

1. 复现问题后，打开 **设置 → 其他 → 日志**。
2. 可以按级别（错误 / 警告 / 信息 / 调试 / 指标）筛选、搜索、暂停。
3. 点「导出」保存到 `下载/MicMask`，或点「分享」直接发送。
4. 没有 Shizuku 或怀疑系统兼容问题时，可以点「自检」，复制 adb 自检命令在电脑上执行，把输出连同日志一起发给开发者。

反馈渠道（**设置 → 其他 → 关于 MicMask → 交流反馈**）：

- **反馈问题**：在 App 内描述问题，可附带日志和截图。
- **QQ 交流群**：780988679（MicMask用户交流群）。
- **GitHub Issues**：<https://github.com/Taocrypt/MicMask/issues>，标题请写上机型和芯片。

反馈时请尽量说明：手机型号、Android 版本、MicMask 版本、运行模式、使用的音色和档位，以及问题发生的步骤。
